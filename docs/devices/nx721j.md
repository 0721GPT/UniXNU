# ZTE Nubia Z60 Ultra (nx721j)

ZTE Nubia Z60 Ultra (nx721j) is a SM8750 device. The port below is an independent community project. The UniXNU organization does not maintain it.

| Repository | Maintainer | State |
| --- | --- | --- |
| [UniXNU-Nubia-Z60U](https://github.com/SangLuoCN/UniXNU-Nubia-Z60U) | [SangLuoCN](https://github.com/SangLuoCN) |

## State

The repository is a kernel bring-up baseline for NX721J. It has no target-specific userdata, firmware or payload yet.

## Maintenance

The maintainer owns the repository and its release decisions. UniXNU documentation lists the port and its state; it does not take over maintenance.
