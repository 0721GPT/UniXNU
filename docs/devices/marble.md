# Redmi Note 12 Turbo / POCO F5 (marble)

Redmi Note 12 Turbo / POCO F5 (marble) is a SM7475 device. The port below is an independent community project. The UniXNU organization does not maintain it.

| Repository | Maintainer | State |
| --- | --- | --- |
| [UniXNU-marble](https://github.com/Enmmmmn/UniXNU-marble) | [Enmmmmn](https://github.com/Enmmmmn) |

## State

Skeleton device repository. `board.toml` still carries TODO values for the userdata LBAs, kernel arguments, trust-cache pins and ADT generator. The kernel step can run with the defconfig and IPSW.

## Maintenance

The maintainer owns the repository and its release decisions. UniXNU documentation lists the port and its state; it does not take over maintenance.
