# Samsung Galaxy Tab S7 FE Wi-Fi (SM-T733)

Samsung Galaxy Tab S7 FE Wi-Fi (SM-T733) is a SM7325 device. The port below is an independent community project. The UniXNU organization does not maintain it.

| Repository | Maintainer | State |
| --- | --- | --- |
| [unixnu-sm-t733](https://github.com/RigoLigoRLC/unixnu-sm-t733) | [RigoLigoRLC](https://github.com/RigoLigoRLC) |
| [unixnu-nativeufs](https://github.com/RigoLigoRLC/unixnu-nativeufs) | [RigoLigoRLC](https://github.com/RigoLigoRLC) | SM7325 UFS, SMMU and root storage |
| [unixnu-nativemobiledisplay](https://github.com/RigoLigoRLC/unixnu-nativemobiledisplay) | [RigoLigoRLC](https://github.com/RigoLigoRLC) | CPU display and framebuffer presentation |
| [unixnu-nativeramblock](https://github.com/RigoLigoRLC/unixnu-nativeramblock) | [RigoLigoRLC](https://github.com/RigoLigoRLC) | Persistent Data and reset handling |
| [unixnu-nativefocaltechtouch](https://github.com/RigoLigoRLC/unixnu-nativefocaltechtouch) | [RigoLigoRLC](https://github.com/RigoLigoRLC) | FT8203 touch over GENI SPI |

## State

UEFI, the UniXNU menu, XNU on eight cores, UFS system and persistent Data work. The desktop, CPU display, FT8203 touch, fuel gauge and USB CDC log work. GPU, Wi-Fi, audio, S Pen and system suspend are pending.

## Maintenance

The maintainer owns the repository and its release decisions. UniXNU documentation lists the port and its state; it does not take over maintenance.
