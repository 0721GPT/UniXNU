# NativeGeniSpi

Qualcomm GENI serial-engine SPI master for the touch controller and other SPI devices.

| Repository | Maintainer | Scope |
| --- | --- | --- |
| [NativeGeniSpi](https://github.com/UniXNU/NativeGeniSpi) | [UniXNU](https://github.com/UniXNU) | Qualcomm GENI serial-engine SPI master for the touch controller and other SPI devices. |

## State

Used by the sheng touch path. The driver has no standalone hardware result.

## Build

Linked into XNU by `unixnu build kernel`, or built by its own script when the repository is a kit or tool.
