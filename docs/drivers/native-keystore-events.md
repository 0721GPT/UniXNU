# NativeKeyStoreEvents

AppleKeyStore state client. Answers the keystore state queries the original userland makes.

| Repository | Maintainer | Scope |
| --- | --- | --- |
| [NativeKeyStoreEvents](https://github.com/UniXNU/NativeKeyStoreEvents) | [UniXNU](https://github.com/UniXNU) | AppleKeyStore state client. Answers the keystore state queries the original userland makes. |

## State

Used by the VM and device ports. No standalone hardware result.

## Build

Linked into XNU by `unixnu build kernel`, or built by its own script when the repository is a kit or tool.
