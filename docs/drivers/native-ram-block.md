# NativeRamBlock

RAM block storage driver. Provides block devices from RAM and an optional persistent Data overlay.

| Repository | Maintainer | Scope |
| --- | --- | --- |
| [NativeRamBlock](https://github.com/UniXNU/NativeRamBlock) | [UniXNU](https://github.com/UniXNU) | RAM block storage driver. Provides block devices from RAM and an optional persistent Data overlay. |

## State

Used for the RAM-backed Data volume and the persistent overlay.

## Build

Linked into XNU by `unixnu build kernel`, or built by its own script when the repository is a kit or tool.
