# NativeHidInput

HID input driver. Publishes touch and hardware buttons through the original IOHID stack.

| Repository | Maintainer | Scope |
| --- | --- | --- |
| [NativeHidInput](https://github.com/UniXNU/NativeHidInput) | [UniXNU](https://github.com/UniXNU) | HID input driver. Publishes touch and hardware buttons through the original IOHID stack. |

## State

Used by sheng and several device ports. The driver has no standalone hardware result.

## Build

Linked into XNU by `unixnu build kernel`, or built by its own script when the repository is a kit or tool.
