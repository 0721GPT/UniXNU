# NativeVirtioConsole

Virtio console transport for logs and bounded offline instruments.

| Repository | Maintainer | Scope |
| --- | --- | --- |
| [NativeVirtioConsole](https://github.com/UniXNU/NativeVirtioConsole) | [UniXNU](https://github.com/UniXNU) | Virtio console transport for logs and bounded offline instruments. |

## State

Used by the QEMU and VM ports. No standalone hardware result.

## Build

Linked into XNU by `unixnu build kernel`, or built by its own script when the repository is a kit or tool.
