# NativeAES

Native AES accelerator driver. Binds the original accelerator class to the recorded XNU ABI.

| Repository | Maintainer | Scope |
| --- | --- | --- |
| [NativeAES](https://github.com/UniXNU/NativeAES) | [UniXNU](https://github.com/UniXNU) | Native AES accelerator driver. Binds the original accelerator class to the recorded XNU ABI. |

## State

Linked into XNU when the board enables the archive. No standalone hardware result.

## Build

Linked into XNU by `unixnu build kernel`, or built by its own script when the repository is a kit or tool.
