# Redmi Note 14 Pro+ 5G（amethyst）

amethyst 是搭载 SM7635 的 Redmi Note 14 Pro+ 5G。下面的移植是独立的社区项目，UniXNU 组织不维护它。目标是 iPhone X（iPhone10,3）用户态。

| 仓库 | 维护者 | 状态 |
| --- | --- | --- |
| [UniXNU-amethyst](https://github.com/andr0d1v/UniXNU-amethyst) | [andr0d1v](https://github.com/andr0d1v) | 板级文件和启用 legacy display 的内核配置，未记录真机运行 |

## 状态

仓库包含 `board.toml`、`configs/amethyst_defconfig` 和 `scripts/check-amethyst.py`。内核配置启用了 legacy display 路径。README 是简短的进行中说明，并记录 UEFI 仍缺失。没有记录真机运行。

## 维护

维护者拥有仓库和发布决定。UniXNU 文档记录移植及其状态，不接管维护。
