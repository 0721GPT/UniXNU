# 努比亚红魔 8 Pro / 8 Pro+（nx729j）

nx729j 是搭载 SM8550 的努比亚红魔 8 Pro 和 8 Pro+。下面的移植是独立的社区项目，UniXNU 组织不维护它。

| 仓库 | 维护者 | 状态 |
| --- | --- | --- |
| [UniXNU-nx729j](https://github.com/2713385115/UniXNU-nx729j) | [2713385115](https://github.com/2713385115) | 设备仓库包含 NativeUfs 和对应流的 SMMU group，运行时未记录 |

## 状态

仓库从 UniXNU-sheng 派生，沿用 iPad7,1 iPadOS 17.7.11 目标。板级文件记录了来自原厂 fastboot 包和设备 GPT 的 userdata 几何，并配置了 SM8550 内核静态库。设备仓库还包含 NativeUfs，并回收了对应流的 SMMU group。

README 仍是 sheng 模板，没有记录运行时状态。面板、触控和 bring-up 数值以仓库为准。

## 维护

维护者拥有仓库和发布决定。UniXNU 文档记录移植及其状态，不接管维护。
