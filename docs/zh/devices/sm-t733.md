# 三星 Galaxy Tab S7 FE Wi-Fi（SM-T733）

三星 Galaxy Tab S7 FE Wi-Fi（SM-T733） 是搭载 SM7325 的设备。下面的移植是独立的社区项目，UniXNU 组织不维护它。

| 仓库 | 维护者 | 状态 |
| --- | --- | --- |
| [unixnu-sm-t733](https://github.com/RigoLigoRLC/unixnu-sm-t733) | [RigoLigoRLC](https://github.com/RigoLigoRLC) |
| [unixnu-nativeufs](https://github.com/RigoLigoRLC/unixnu-nativeufs) | [RigoLigoRLC](https://github.com/RigoLigoRLC) | SM7325 UFS、SMMU 和根存储 |
| [unixnu-nativemobiledisplay](https://github.com/RigoLigoRLC/unixnu-nativemobiledisplay) | [RigoLigoRLC](https://github.com/RigoLigoRLC) | CPU 显示和 framebuffer 呈现 |
| [unixnu-nativeramblock](https://github.com/RigoLigoRLC/unixnu-nativeramblock) | [RigoLigoRLC](https://github.com/RigoLigoRLC) | 持久 Data 和复位处理 |
| [unixnu-nativefocaltechtouch](https://github.com/RigoLigoRLC/unixnu-nativefocaltechtouch) | [RigoLigoRLC](https://github.com/RigoLigoRLC) | GENI SPI 上的 FT8203 触控 |

## 状态

UEFI、UniXNU 菜单、8 核 XNU、UFS 系统和持久 Data 工作。桌面、CPU 显示、FT8203 触控、电量计和 USB CDC 日志工作。GPU、Wi-Fi、音频、S Pen 和系统休眠待完成。

## 维护

维护者拥有仓库和发布决定。UniXNU 文档记录移植及其状态，不接管维护。
