# SM8550 支持

[`UniXNU-sm8550-common`](https://github.com/UniXNU/UniXNU-sm8550-common)
提供 SM8550 配置、DTSI、平台操作和 XNU 补丁系列。
[`UniXNU-sheng`](https://github.com/UniXNU/UniXNU-sheng) 提供小米平板 6S Pro 的板级配置。

| 归属 | 数据与代码 |
| --- | --- |
| SoC | CPU 拓扑、GIC、计时器、GPU/GMU/SMMU 资源、共享平台操作 |
| 设备 | 启用的 CPU、内存区域、签名固件选择、电源策略、外设连接、显示集成和分区 |
| OS 配置 | XNU/IPSW 版本、Apple 身份、预链接根组件、ABI 要求 |
| 组件 | Adreno740、AdrenoMetal、AdrenoPM4、AdrenoFirmware、ArmSmmu4K 和所选驱动 |

添加设备前，阅读 `soc.toml`、`dts/sm8550.dtsi` 和根目录的 `AGENTS.md`。
板级 DTS 包含 DTSI 并描述设备资源，设备的 `feeds.toml` 固定 SoC 源码版本。

Adreno740 和 AdrenoMetal 的实现范围为 A740/SM8550。sheng 记录了 GPU 硬件结果。
每个设备提供自己的固件、电源、保留内存和显示输入，并记录验证结果。

sheng 的 UFS、触控和 HID 实现由其设备配置选择。为其他设备选择组件时，核对这些
组件的接口与板级依赖。
