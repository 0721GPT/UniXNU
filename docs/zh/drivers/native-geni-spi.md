# NativeGeniSpi

高通 GENI 串行引擎 SPI 主机，用于触控控制器和其他 SPI 设备。

| 仓库 | 维护者 | 范围 |
| --- | --- | --- |
| [NativeGeniSpi](https://github.com/UniXNU/NativeGeniSpi) | [UniXNU](https://github.com/UniXNU) | 高通 GENI 串行引擎 SPI 主机，用于触控控制器和其他 SPI 设备。 |

## 状态

用于 sheng 触控路径。驱动没有独立的真机结果。

## 构建

通过 `unixnu build kernel` 链接进 XNU；kit 或工具仓库用自己的脚本构建。
