# NativeRamBlock

RAM 块存储驱动。从内存提供块设备，并支持可选的持久 Data overlay。

| 仓库 | 维护者 | 范围 |
| --- | --- | --- |
| [NativeRamBlock](https://github.com/UniXNU/NativeRamBlock) | [UniXNU](https://github.com/UniXNU) | RAM 块存储驱动。从内存提供块设备，并支持可选的持久 Data overlay。 |

## 状态

用于内存 Data 卷和持久 overlay。

## 构建

通过 `unixnu build kernel` 链接进 XNU；kit 或工具仓库用自己的脚本构建。
