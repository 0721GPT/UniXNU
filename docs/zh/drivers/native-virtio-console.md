# NativeVirtioConsole

Virtio 控制台传输，用于日志和有界离线仪器。

| 仓库 | 维护者 | 范围 |
| --- | --- | --- |
| [NativeVirtioConsole](https://github.com/UniXNU/NativeVirtioConsole) | [UniXNU](https://github.com/UniXNU) | Virtio 控制台传输，用于日志和有界离线仪器。 |

## 状态

QEMU 和虚拟机移植使用它。没有独立真机结果。

## 构建

通过 `unixnu build kernel` 链接进 XNU；kit 或工具仓库用自己的脚本构建。
