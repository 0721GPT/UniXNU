# SM8550 support

[`UniXNU-sm8550-common`](https://github.com/UniXNU/UniXNU-sm8550-common)
provides SM8550 profiles, DTSI, platform operations, and XNU patch series.
[`UniXNU-sheng`](https://github.com/UniXNU/UniXNU-sheng) supplies the Xiaomi Pad
6S Pro board configuration.

| Owner | Data and code |
| --- | --- |
| SoC | CPU topology, GIC, timer, GPU/GMU/SMMU resources, shared platform operations |
| Device | Enabled CPUs, memory regions, signed firmware selection, power policy, peripheral wiring, display integration, partitions |
| OS profile | XNU/IPSW versions, Apple identity, prelink roots, ABI requirements |
| Components | Adreno740, AdrenoMetal, AdrenoPM4, AdrenoFirmware, ArmSmmu4K and selected drivers |

Read `soc.toml`, `dts/sm8550.dtsi`, and the root `AGENTS.md` before adding a board.
Include the DTSI and describe board resources in the device DTS. Pin the SoC
source in the device's `feeds.toml`.

Adreno740 and AdrenoMetal have A740/SM8550 implementation coverage. sheng records
GPU hardware results. Each board supplies firmware, power, reserved-memory,
and display inputs and records its own verification.

The sheng UFS, touch, and HID implementations are selected by its device
profile. Reuse their documented interfaces and board dependencies when
selecting components for another port.

- [Device repository](/porting/device-repository)
- [Device tree](/porting/device-tree)
- [sheng](/devices/sheng)
- [Migration](/porting/migration)

For another SM8550 board, follow [Port a device](/porting/) and the [driver adaptation checklist](/porting/drivers). The GPU, brightness, touch and Wi-Fi guides identify the board inputs and source integration points.
